# License decision (open)

No `LICENSE` file is included on purpose. Choosing a license is the repository owner's decision and changes what others may do with the code.
Until a license is chosen, the default legal position applies: all rights reserved by the author; the repository is private.

Suggested options when deciding: MIT or Apache-2.0 (permissive; Apache-2.0 adds a patent grant, useful for a networking/safety project), GPL-3.0 (copyleft), or keep proprietary.
Dependencies added for Android must have licenses compatible with the chosen option.
